# PowerBI-Banking-Dashboard
Interactive Banking Analytics Dashboard built with Power BI, Excel, Power Query and DAX for analyzing loans, deposits, revenue, profit and customer performance.
# Banking Analytics Dashboard | Power BI

## Project Overview

This project presents an interactive Banking Analytics Dashboard developed using Microsoft Power BI. The dashboard provides insights into key banking metrics, including loans, deposits, revenue, profit, customer segments, product performance, and geographic distribution.

The objective of this project is to transform raw banking data into meaningful business insights through interactive data visualization and analysis.

---

## Dashboard Pages

### Page 1: Banking Overview

This page provides a high-level overview of key banking performance indicators.

Key insights include:

- Total Loans
- Total Deposits
- Total Revenue
- Total Profit
- Customer Distribution
- Product Performance
- Branch and Regional Analysis
